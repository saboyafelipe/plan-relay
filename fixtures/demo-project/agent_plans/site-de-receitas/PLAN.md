# site-de-receitas — plano geral

Um site estático que lista receitas a partir de arquivos Markdown, com busca por ingrediente.

## Fases

- **Fase 0 — Base:** estrutura do projeto, gerador do site e a primeira página.
- **Fase 1 — Busca:** índice de ingredientes e a página de busca.

## Fora de escopo

Contas de usuário, comentários, busca por voz e qualquer servidor além do que serve os arquivos estáticos.
